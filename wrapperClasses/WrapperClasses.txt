Wrapper Classes are used to convert primitive data types into objects.

Java provides a class for each primitive type in the package java.lang.
Primitive   vs      Wrapper Classes
byte	              Byte
short               Short
int	                Integer
long	              Long
float	              Float  
etc ..

int a = 10;          // primitive
Integer b = 10;      // wrapper object

Why Wrapper Classes Are Needed
1. Collections require objects
Classes in Java Collections Framework only work with objects.

ArrayList<Integer> list = new ArrayList<>();
list.add(10);
Primitive int cannot be stored directly in collections.

Primitive types cannot store null, but wrapper objects can.
Integer a = null;

Autoboxing and Unboxing
Autoboxing

Java automatically converts primitive → wrapper object.
int a = 5;
Integer b = a;   // autoboxing

Unboxing
Wrapper → primitive.
Integer obj = 10;
int b = obj;      // unboxing
